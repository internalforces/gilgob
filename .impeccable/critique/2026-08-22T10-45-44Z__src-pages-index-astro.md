# Design Specificity Verdict

**사람 관점 평가:** 한국어 지식 정원이라는 정체성은 카피, 연결 수치, 학습 기록에서 드러납니다. 그러나 Geist, 옅은 청색 캔버스, 남색 카드, 궤도·레이더·노드 그래픽은 개발자 포트폴리오나 SaaS 분석 화면에도 거의 그대로 옮길 수 있습니다. 실제 문서 관계와 탐구의 변화 대신 추상 텔레메트리가 반복됩니다.

**결정적 스캔:** `src/pages/index.astro:185`에서 `padding-inline` 전환 1건을 발견했습니다. 실제 레이아웃 계산을 유발하지만 두 개의 하단 링크에만 적용돼 P3입니다. 화살표나 내부 요소의 `transform` 이동으로 바꾸면 됩니다.

**브라우저 증거:** 자동 스캔이 놓친 중대한 결함이 있습니다. `src/components/github/ContributionCalendar.astro:70,104`의 숨김 표가 표 레이아웃 높이를 유지해 문서 바깥으로 약 10,000px 늘어납니다. 데스크톱 문서 높이는 15,044px였지만 정상 콘텐츠와 푸터는 약 5,317px에서 끝났고, 모바일은 15,923px 중 약 5,434px 이후가 사실상 빈 공간이었습니다. 브라우저에 변경 가능한 스크립트 주입 기능이 없어 사용자용 오버레이는 표시하지 못했으며, 화면 캡처·DOM 치수·스크롤 측정으로 확인했습니다.

# Overall Impression

첫 화면은 자신감 있고 검색을 중심 행동으로 잘 세웠습니다. 반면 그 뒤에는 필드, 신호, 로그, 프로젝트, GitHub, 반복 링크가 모두 비슷한 비중으로 이어져 편집 의도가 약해집니다. 가장 큰 기회는 푸터 뒤 빈 스크롤 결함을 먼저 제거하고, 홈페이지를 “모든 현황의 대시보드”에서 “가장 좋은 지식 관계로 들어가는 안내자”로 바꾸는 것입니다.

인지 부하는 **8개 항목 중 5개 실패로 높음**입니다. 단일 초점, 4개 이하 청킹, 명확한 그룹화, 최소 선택지, 점진적 공개가 실패했습니다. 데스크톱 주 탐색은 7개 목적지, 모바일 메뉴는 9개 행동, 필드 인덱스는 8개 동등 선택지입니다.

감정 여정은 명확한 헤드라인과 검색으로 강하게 시작하지만, 곧바로 여러 `0개의 기록` 카드가 등장하며 희소함을 강조합니다. 구체적 프로젝트와 GitHub 활동에서 다시 신뢰가 생기지만, 하단의 반복 링크와 거대한 빈 스크롤 꼬리가 마지막 인상을 망칩니다.

# What's Working

1. **검색 중심의 첫 화면:** 한국어 헤드라인, 넓은 검색 트리거, Cmd/Ctrl+K 안내가 지식 아카이브의 핵심 행동을 분명하게 만듭니다.
2. **상태와 접근성 배려:** 검색의 로딩·빈 결과·오류 문구, skip link, 전역 포커스, reduced-motion, 기여 캘린더의 텍스트 대체가 잘 준비돼 있습니다.
3. **안정적인 반응형 구성:** 390px에서 가로 넘침이 없고 핵심 터치 대상이 충분히 큽니다. GitHub 영역도 한 열로 자연스럽게 쌓입니다.

# Priority Issues

## [P1] 푸터 뒤에 약 10,000px의 빈 스크롤이 이어집니다

- **왜 중요한가:** 사용자는 페이지가 끝났는지 알 수 없고, 모바일에서는 고장 난 화면처럼 긴 빈 공간을 계속 스크롤할 수 있습니다.
- **수정:** 큰 `<table>` 자체에 visually-hidden 스타일을 적용하지 말고, 견고한 공용 스크린리더 전용 래퍼로 감싸 표 레이아웃이 문서 높이를 확장하지 않게 해야 합니다.
- **근거:** `src/components/github/ContributionCalendar.astro:70,104`
- **추천 명령:** `$impeccable harden src/components/github/ContributionCalendar.astro`

## [P1] 홈페이지에 하나의 편집 우선순위가 없습니다

- **왜 중요한가:** 첫 방문자가 검색, 8개 필드, 3개 신호, 로그, 프로젝트, GitHub 중 무엇이 가장 중요한지 판단해야 합니다.
- **수정:** 검색과 하나의 큐레이션된 “여기서 시작” 경로를 중심으로 두고, 현황성 섹션은 점진적으로 공개하거나 후순위로 낮춥니다.

## [P1] 모바일 메뉴가 9개 행동을 한 번에 보여주는 약한 모달입니다

- **근거:** `src/components/navigation/MobileMenu.tsx:20-34,50-86`

## [P2] 추상 지표와 그래픽이 지식 정원의 신뢰성과 고유성을 약화합니다
